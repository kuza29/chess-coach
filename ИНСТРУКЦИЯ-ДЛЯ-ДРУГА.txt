ШАХМАТНЫЙ ТРЕНЕР — инструкция
================================================

ЧТО ЭТО
Программа смотрит на доску на chess.com и в отдельном маленьком окне
показывает лучший ход по версии Stockfish (сильнейший шахматный движок),
оценку позиции и линию продолжения. На доске рисуется зелёная стрелка.

Всё считается на твоём компьютере: ничего не скачивается и никуда
не отправляется, интернет нужен только для установки.

ВАЖНО: в рейтинговых партиях онлайн подсказки движка запрещены правилами
chess.com — за это блокируют аккаунт. Используй в тренировке с компьютером
и в разборе своих партий.

ЧТО НУЖНО
- Windows 10 или 11 (64 бит)
- Браузер Firefox или Chrome
- Python НЕ нужен — всё уже собрано

================================================
ШАГ 1. Распакуй архив
================================================
Правый клик по архиву → «Извлечь все…» → выбери папку (например, Рабочий стол).
Запускать .exe прямо из архива нельзя — только из распакованной папки.

Внутри папки должно быть:
    ChessCoach.exe
    _internal\        (служебная папка, не трогай)
    engine\           (Stockfish)
    userscript\       (скрипт для браузера, пригодится на шаге 4)
    ИНСТРУКЦИЯ.txt

================================================
ШАГ 2. Запусти программу
================================================
Двойной клик по ChessCoach.exe

- Windows может сказать «Система Windows защитила ваш компьютер»:
  нажми «Подробнее» → «Выполнить в любом случае». Это нормально —
  у программы просто нет платной цифровой подписи.
- Появятся ДВА окна:
    1) чёрная консоль — это сервер, его НЕ ЗАКРЫВАТЬ;
    2) маленькое тёмное окно «Тренер» — оно всегда поверх всех окон.
- В браузере сама откроется страница проверки.

================================================
ШАГ 3. Поставь расширение Tampermonkey
================================================
1. Открой https://www.tampermonkey.net/
2. Нажми «Download» и выбери свой браузер.
3. Подтверди установку и разреши расширению работу.

================================================
ШАГ 4. Поставь скрипт, который читает доску
================================================
Чёрное окно консоли должно быть открыто!

1. Открой в браузере:   http://127.0.0.1:8765/
2. Нажми на странице ссылку «chess-coach.user.js».
3. Tampermonkey покажет страницу с кодом и кнопку «Установить» (Install).
   Нажми её.

Если ссылка не открывается — значит программа не запущена (шаг 2).

================================================
ШАГ 5. Играй
================================================
1. Открой https://www.chess.com — например, «Играть» → «С компьютером».
2. Нажми F5 (обновить страницу). Скрипт включается только при загрузке.
3. Готово: на доске зелёная стрелка и плашка с ходом,
   в окне «Тренер» — ход, оценка и линия.

ГОРЯЧИЕ КЛАВИШИ
  Alt + C              — включить/выключить стрелку
  Alt + D              — диагностика: показывает, какую позицию прочитал
  Shift + клик по плашке на доске — перевернуть доску, если стрелка
                         рисуется зеркально (когда играешь чёрными)
  Правый клик по окну «Тренер» — скорость анализа (0.15–2 сек),
                         число линий, копировать FEN, выход

================================================
ЕСЛИ НЕ РАБОТАЕТ
================================================
Открой http://127.0.0.1:8765/ — там 4 пункта с галочками.
Где крестик — то и не работает:

[1] Сервер   ✕ → программа не запущена или закрыто чёрное окно консоли
[2] Движок   ✕ → не хватает файла engine\stockfish.exe (распакуй архив
                 целиком, папку engine не удаляй)
[3] Скрипт   ✕ → скрипт не установлен в Tampermonkey (шаг 4),
                 либо играешь в браузере без Tampermonkey,
                 либо не сделал F5 на странице chess.com
[4] Доска    ✕ → доска не читается. Нажми Alt+D на chess.com и посмотри,
                 что написано в плашке на доске

Окно «Тренер» пишет «ожидание позиции из браузера»
   → сервер работает, но скрипт в браузере молчит: повтори шаги 3–5.
Окно «Тренер» пишет «нет связи с сервером»
   → закрылось чёрное окно консоли. Запусти ChessCoach.exe заново.

================================================
ПРОЧЕЕ
================================================
- «Порт 8765 занят» → программа уже запущена. Найди старое чёрное окно
  и закрой его (или перезагрузи компьютер).
- Не переноси ChessCoach.exe отдельно от папок _internal и engine —
  работать не будет.
- Хочешь быстрее/точнее: правый клик по окну «Тренер» → «Скорость анализа».
- Антивирус может спросить про сеть — разреши для домашней сети;
  программа слушает только свой компьютер (127.0.0.1).
